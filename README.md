# LiveTL

在 Ren'Py 游戏里直接做翻译：**边玩边译，写完立刻看到效果**。

面板嵌在游戏窗口里，跟着剧情显示当前台词原文（`{w}`、`{p}` 这类标签原样保留）：
输入译文、写回 `game/tl/`、点【重载】当场生效，全程不用切换编辑器。

此为一个vibe coding项目

## 项目特色

- **边玩边译**：面板跟着剧情走，提交写回 tl 文件，【重载】立即看到新译文。
- **不改动游戏原有文件**：`livetl/` 整个放进 `game/` 就能用；没翻的句子照常显示原文。
- **官方格式的增量模板**：按 Ren'Py 官方格式生成翻译模板，只补新台词，翻过的一律不动。
- **对话之外的文本也能翻**：菜单选项列成列表逐条翻；界面文本按 `F9` 拾取点选翻译。
- **顺手的中文输入**：输入法候选框跟随输入框，鼠标点选、复制粘贴、撤销重做都能用。
- **自带字体替换**：一键把游戏字体换成思源黑体，解决汉化后原文显示成方块。
- **重复条目体检**：启动自动检查会让 Ren'Py 报错的重复条目，可一键清理（先备份）。

## 使用方法

### 安装

把 `livetl/` 整个复制进游戏的 `game/` 目录即可，不用改动游戏任何文件。
要求游戏是脚本目录形式（`game/tl/` 可写）；打包成 `.rpa` 的游戏不支持写入。

### 第一次启动

右上角会出现设置界面：选**目标语言**（`translate` 语句里的名字，如 `schinese`；也能新填一个），
点【开始翻译】生成模板并自动切到该语言。之后改设置点面板上的【设置】。

### 日常使用

- 面板跟着剧情自动切到当前台词；输入译文，点【提交】写回，点【重载】当场看到新译文
  （可以攒几段一起重载）。
- 输入框支持中文输入法和鼠标操作：点选、拖选、双击选词、`Ctrl+C / X / V`、`Ctrl+Z` 撤销。
- 原文行可以直接拖选复制；点一下原文行，`Ctrl+A` / `Ctrl+C` 归原文，点回输入框还给译文。
- 菜单出现时面板切成菜单列表，点一条即可翻译；界面文本按 `F9` 拾取点选，`Esc` 退出。
- 点【折叠】或按 `F8` 收起面板；游戏自己弹输入框（如输入名字）时面板自动折叠。
- 【清空】对话只清译文；字符串条目整条删除——空译文会让菜单项变成不可点的空按钮。
- 换行写 `\n`，原文与译文都按字面进出。

快捷键默认 `F8` 折叠、`F9` 拾取；提交 / 重载 / 清空默认不绑，可在【设置】里改。

重复的 `old` 会让 Ren'Py 启动报错：插件启动检查一次，发现后在状态栏提示，
【设置】→【检查重复】能看位置并一键清理（清理前自动备份整个 `tl/<语言>/`）。

## 更改配置项

全部可调项都在 `livetl/livetl_config.rpy`，每项都带注释，改完重开游戏生效。
译者在【设置】里改的语言、字体、快捷键会写回这个文件（原文件先备份 `.bak`）。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `livetl_language` | `"schinese"` | 目标语言；手改等于直接选定 |
| `livetl_font` | 内置思源黑体 | 游戏字体；留空 = 不替换 |
| `livetl_panel_font` | `""` | 面板字体；留空 = 跟随游戏字体 |
| `livetl_hotkey` / `livetl_pick_hotkey` | `"K_F8"` / `"K_F9"` | 折叠面板 / 拾取模式 |
| `livetl_position` | `"top-right"` | 面板位置，可选 `bottom-right` |
| `livetl_ui_scale` | `None` | 面板缩放；`None` = 按画布自动（1080p = 1.0），可填数字覆盖 |
| `livetl_autocomplete_on_start` | `True` | 启动时自动增量补模板 |

**字体**：【设置】→【选择字体】即可更换，桌面平台也可以把字体文件直接拖进游戏窗口，
换完当场生效。请用静态字重（`.otf` / `.ttf`）；可变字体（文件名带 `VF`）会渲染成方块。

## 已知局限

- 只支持脚本目录形式的游戏（`game/tl/` 可写）。
- 输入框、图标按钮、动态拼接的文本拾取不到，这类要直接翻 tl 模板条目。
- 不做 `{#tag}` 上下文区分：一条原文只对应一条译文，也不支持跨句合并或拆分。
- 改键不能绑裸字母数字（要留给输入框），也不能绑 `Ctrl` / `Shift` / `Alt` 本身。

## 版本兼容性

Ren'Py **8.1.1** 与 **8.5.3** 上完整流程实测通过（中文输入、写回、热重载、菜单与拾取）。
引擎内部接口统一封在适配文件里，升级后看 `game/livetl.log` 开头的自检几行即可。
当前版本 **0.6.3**，见 `livetl/version.txt`。
