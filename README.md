# LiveTL

在 Ren'Py 游戏里直接做翻译：**边玩边译，写完立刻看到效果**。

不用在编辑器和游戏窗口之间来回切换——面板就在游戏里，显示当前台词的原文
（`{w}`、`{p}` 这类文本标签原样保留），输入译文、写回文件、一键重载，全程不离开游戏。

此为一个vibe coding项目

## 安装

把 `livetl/` 目录整个放进游戏的 `game/` 目录即可，**不需要改动游戏原有的任何文件**：

```
<你的游戏>/
  game/
    livetl/
      livetl_config.rpy      配置
      livetl_core.rpy        核心逻辑（定位台词、写回、重载）
      livetl_setup.rpy       启动引导
      livetl_ui.rpy          悬浮面板
      livetl_fonts.rpy       字体替换
      fonts/
        SourceHanSansSC-Regular.otf   （自己准备的字体）
        SourceHanSansSC-Bold.otf
```

要求游戏是**脚本目录形式**（能读写 `game/tl/`）。打包进 `.rpa` 的游戏暂不支持写入。

## 使用方法

### 第一次使用

1. 启动游戏，右上角的悬浮框会显示**设置界面**（只有还没定过目标语言时才会这样；
   定过之后启动就直接进翻译界面，想改设置点面板上的【设置】）
2. 填写**目标语言**（就是 `tl` 目录名，例如 `schinese`、`tchinese`、`japanese`）：
   只能用字母、数字、下划线，且不能以数字开头。语言名同时是 Ren'Py
   `translate` 语句里的名字，乱填会让生成的翻译文件解析不了，插件会把
   不合法的输入拦下来并提示
3. 选择**没翻过的句子在游戏里怎么显示**：
   - **留空**：显示为空白
   - **显示原文**：照常读到原文，便于边读边翻（默认）
4. 点【开始翻译】，插件会：
   - 在 `tl/<语言>/` 下按 **Ren'Py 官方格式**生成整套翻译模板
     （每个脚本一个文件、每句对话一个 `translate` 块、原文写在 `#` 注释里）
   - **自动把游戏切换到目标语言**（否则你会看到"提交了但没变化"）

   > 这一步是**增量**的：你点的每一次【开始翻译】都会重新扫一遍项目，
   > 已经翻好的条目原样保留，只补新增的台词与字符串；本轮有新增内容的
   > 文件会在新增条目前面写一行 `# TODO: Translation updated at ...`，
   > 方便对照剧本改动，没有新增的文件不会被动，也不会多出 TODO。
   > 所以剧本更新之后，回到设置界面再点一次【开始翻译】即可补全。

### 日常翻译

面板会跟着剧情自动切换到当前台词。常用操作：

| 想做的事 | 怎么做 |
| --- | --- |
| 看原文 | 面板顶部显示当前台词原文，文本标签原样保留 |
| 输入译文 | **直接打字**；想改中间某个字，用鼠标点一下输入框就能把光标放过去 |
| 选中一段文字 | 按住左键拖过去；双击选一个词，三击全选，`Ctrl+A` 同样是全选 |
| 复制 / 剪切 / 粘贴 | `Ctrl+C` 复制选中的部分（没选中就复制全部），`Ctrl+X` 剪切选中的部分，`Ctrl+V` 粘贴到光标处 |
| 替换 / 删掉选中的部分 | 选中之后直接打字就是替换；按退格或 Delete 只删掉选中那一段 |
| 撤销 / 重做 | `Ctrl+Z` 撤销（连续打字算一步），`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；换到另一条时历史清空 |
| 写换行 | 原文与译文里的换行都按 `\n` 的字面形式进出：面板显示成 `\n`，你在输入框里写 `\n`，写回 tl 后就是真正的换行 |
| 确认输入法候选词 | 空格或回车 |
| 提交 | 点【提交】：把译文写回当前这一条 tl 条目 |
| 清空当前条目 | 点【清空】（会先确认）：对话只清掉译文、条目保留；字符串条目会从 tl 里整条删除 |
| 看效果 | 点【重载】：保存进度 → 重载脚本 → 回到同一句，画面即新译文 |
| 连续翻译 | 可以只提交不重载，翻完一段再统一重载 |
| 折叠 / 展开 | 点【折叠】，屏幕角落留一个小按钮；快捷键 `F8` |
| 改快捷键 | 点【设置】→ 快捷键区点【改键】，再按你想用的键（Esc 取消，退格改成不绑定）。字母和数字要留给输入框打字，所以只能绑功能键或带 Ctrl / Alt / Shift 的组合，`Ctrl` / `Shift` / `Alt` 本身不能绑（按 `Ctrl+S` 时 `Ctrl` 那一下先到，插件会继续等后面那个键）；等按键期间按下的键只归面板：不会漏给游戏，也不会把当前对话推进，按住 `Ctrl` 触发的那次快进会被立刻停掉。改动会写回 `livetl_config.rpy`（原文件先备份成 `.bak`），跟着项目源码走 |
| 改设置 | 点【设置】回到设置界面（换语言、改显示方式、换字体） |
| 换字体 | 点【设置】→【选择字体】从列表里挑一个；桌面平台也可以把字体文件直接拖进游戏窗口 |
| 剧本更新后补条目 | 点【设置】→ 再点一次【开始翻译】：增量补全新台词与新界面文本 |
| 游戏自己弹输入框时 | 面板会**自动折叠**成角落的小按钮（例如让玩家输入名字时），输入完自动展开回原状态，不影响游戏的输入法与回车 |

**关于重载**：提交与重载是分开的两个动作。重载会让游戏短暂重建
（保存 → 重载脚本 → 读回存档），连续翻译时可以先不重载，感觉节奏更顺。

**关于输入法**：面板输入框正常支持中文输入法，候选框会自动定位到输入框下方。
写中文时先按空格/回车把候选词上屏，再点【提交】。

### 菜单与界面文本

菜单、按钮、界面提示这类文本在 Ren'Py 里属于**字符串条目**
（tl 文件里的 `translate <语言> strings:`），和对话是两套东西。
插件用两种方式处理它们：

- **菜单**：游戏弹出选项时，面板自动切成菜单列表，一次性列出当前菜单的
  所有条目（原文 + 已翻/未翻状态）。点某一条即可在下方输入框里翻译，
  提交后写回 tl，状态立即变「已翻」。
- **界面文本**：用下面的拾取模式，点到哪条翻哪条。

拾取只认"有原文的文本"。输入框（例如存档页的 `Page 1`）、图标/图片按钮、
运行时代码拼出来的文本都拾不到——面板会说明是哪种情况。这几类的译文要写进
tl 的模板条目里，例如 `_("Page {}")`、`_("SAVE [SLOT]\n%A, %B %d %Y, %H:%M")`。

写回时遵循 Ren'Py 官方的归属规则（该文本本来属于哪个 tl 文件就写回哪里），
并且**写入前会做全文件查重**——同一个原文只会有一条译文，不会产生
让游戏启动报错的重复条目。

面板上的【清空】对两类条目的含义不同：对话只把译文清成空串（`translate`
块由源码决定，删不掉也不该删）；字符串条目则是从 tl 里整条删除，
因为空的字符串译文会让菜单项变成不可点的空按钮。

### 拾取模式

面板上点【拾取】（或按 `F9`）进入拾取模式：面板收起，鼠标移到画面上任意
文本上会实时显示它的原文，点一下即可交给面板翻译；按 `Esc` 退出。

拾取到菜单里的条目时会直接选中菜单列表里的那一条；拾取到其它界面文本
（设置项、按钮、提示）时按字符串条目处理。若拾取到的是当前这句对话，
面板会提示回到对话模式。

### 查重体检

同一语言下重复的 `old` 会让 Ren'Py **启动直接报错**
（`A translation for "..." already exists`）。插件会在启动后检查一次，
发现重复就在状态栏提示；点【设置】里的【检查重复】进入体检界面，
可以看到每条重复出现在哪个文件哪一行，并按【清理】一键处理
（保留第一条，清理前会把整个 `tl/<语言>/` 备份到 `game/livetl_backup/`）。

## 配置

所有可调项都在 `livetl/livetl_config.rpy`：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `livetl_language` | `"schinese"` | 缺省目标语言（`tl` 目录名），也是设置界面预填的值 |
| `livetl_show_setup_on_start` | `False` | 是否每次启动都先显示设置界面；默认只在还没定过目标语言时问一次 |
| `livetl_show_source_when_empty` | `True` | 没翻过的句子显示原文（`False` 则留空） |
| `livetl_hotkey` | `"K_F8"` | 显示 / 折叠面板（面板折叠时也有效） |
| `livetl_pick_hotkey` | `"K_F9"` | 拾取模式（面板折叠时也有效） |
| `livetl_submit_hotkey` | `""` | 提交；只在面板展开时生效，留空 = 不绑 |
| `livetl_reload_hotkey` | `""` | 重载；只在面板展开时生效，留空 = 不绑 |
| `livetl_clear_hotkey` | `""` | 清空（同样会先确认）；只在面板展开时生效 |
| `livetl_position` | `"top-right"` | 面板位置：`top-right` / `bottom-right` |
| `livetl_panel_width` | `680` | 面板宽度（像素） |
| `livetl_input_select_color` | `"#ffcc6666"` | 输入框里选中文字时的底色（带透明度的颜色写法） |
| `livetl_menu_list_height` | `260` | 菜单列表最大高度（像素），超出后列表内滚动 |
| `livetl_font` | `"livetl/fonts/SourceHanSansSC-Regular.otf"` | 游戏字体：把游戏里用到的字体统一换成它；留空用游戏原字体 |
| `livetl_panel_font` | `""` | 面板字体；留空跟随游戏字体 |
| `livetl_show_id` | `False` | 显示当前句的翻译标识符（排查问题用） |
| `livetl_dup_check_on_start` | `True` | 启动时自动检查重复字符串条目（只提示，不自动改） |
| `livetl_debug` | `True` | 是否写 `game/livetl.log` |

## 字体

汉化后原文的字体往往不含中文字形（显示成方块）。插件会扫描游戏脚本里用到的字体，
并通过 Ren'Py 自带的 `config.font_replacement_map` 把它们统一替换成 `livetl_font`
（默认是随插件附带的思源黑体简体）。`livetl_font` 留空则不替换，游戏用回自己的字体。

随插件附带：

| 文件 | 说明 |
| --- | --- |
| `livetl/fonts/SourceHanSansSC-Regular.otf` | 思源黑体简体（Source Han Sans SC），Regular 字重 |
| `livetl/fonts/LICENSE.txt` | 该字体的 SIL Open Font License 1.1 许可 |

插件只带了一个字重，粗体由 Ren'Py 自行处理（按字号膨胀位图的伪粗体）。注意游戏里
常见的那种"粗体标题"往往是另一个字体文件（例如 `Manrope-Bold.ttf`），替换后会变成
普通字重。

**关于许可**：思源黑体采用 OFL 1.1，允许随软件打包、再分发和商用，条件是
**每一份副本都要带上版权声明和许可文件**。所以：

- 分发本插件时，请连同 `livetl/fonts/LICENSE.txt` 一起
- 把字体打包进游戏发行时，游戏那一份同样要带上这个许可文件

### 换成别的字体

设置界面里点【选择字体】会列出 `livetl/fonts/` 下所有可用字体，点一个就换过去；
桌面平台上还可以**把字体文件直接拖进游戏窗口**——拖进去的那一份会被复制到
`livetl/fonts/`，再用它当游戏字体（目录里已有同名文件、内容又不一样时不会覆盖，
会提示你先改名）。两种方式都会把结果写进
`livetl/livetl_config.rpy` 的 `livetl_font`，改之前先把原文件备份成
`livetl_config.rpy.bak`（只保留最近一次）。

也可以手动改：

```renpy
livetl_font       = "livetl/fonts/你的字体.otf"   # 游戏字体，留空 = 不替换
livetl_panel_font = ""                           # 面板字体，留空 = 跟随游戏字体
```

`livetl_font` 留空表示**不做字体替换**，游戏原本的字体照常使用。换完字体当场生效
（插件会重建替换表并清掉文本排版缓存），不需要重启游戏。

三点注意：

- 请用**静态字重**（`.otf` / `.ttf`）。可变字体（文件名常带 `VF`）在 Ren'Py 里
  不会渲染，中文会显示成方块；列表里这类字体会标出来。
- Ren'Py 虽然支持 `.ttc` / `.otc` 字体集合，但只能用集合里的**第一个**字体，
  所以不推荐 Super OTC 这类合集。
- 拖放只在桌面平台（Windows / macOS / Linux）上有；手机、平板上用【选择字体】。
  打包后的游戏里往往只剩 `.rpyc`，改不了配置文件，那时插件会只改本次运行并
  在状态栏说明原因。

## 工作原理

| 环节 | 用到的接口 |
| --- | --- |
| 定位当前台词 | `renpy.get_translation_identifier()` |
| 读取原文 | 默认语言节点 `translator.default_translates` |
| 生成 tl 模板 | `renpy.translation.generation.write_translates()` / `write_strings()`（官方生成逻辑，增量补全：已翻条目跳过、新增条目写 TODO） |
| 写回单条 | 按官方格式替换对应 `translate` 块里的译文行，文件其余内容不动 |
| 写回字符串条目 | 扫描 tl 全量查重 → 命中就改那条 `new`，未命中按官方归属文件新增 |
| 菜单条目列表 | 读 `choice` screen 的 items（`caption` 即原文），配 tl 索引得到状态 |
| 拾取界面文本 | `Render.main_displayables_at_point()` 取鼠标下的元素，`Text.text_parameter` 即原文 |
| 拾取层屏蔽游戏操作 | modal screen + 全屏按钮（显示/隐藏后需要 `renpy.restart_interaction()`） |
| 面板内点击不穿透 | frame 的 `modal` 属性（鼠标在面板范围内时，事件不再传给下层的游戏） |
| 输入框的鼠标定位与选区 | 官方 `Input` 只认键盘（8.1.1 / 8.5.3 都一样，鼠标点击既不动光标也不挡事件），插件用自己的控件补：读 `Text` 排版的字形坐标换算字符下标，选区画成一层半透明底色 |
| 重复条目体检 | 扫描 tl 里的 `old` 位置；清理时保留第一条并整目录备份 |
| 热重载 | `renpy.reload_script()`（保存 → 重载脚本 → 读回存档） |
| 重载后重绘当前句 | 读档只恢复"已显示的对话"，不会重跑当前语句，插件会跳回该句重新执行 |
| 未翻译时显示原文 | `config.say_menu_text_filter`（渲染阶段替换，不改动 tl 文件） |
| 字体替换 | `config.font_replacement_map` |
| 拖入字体 | `config.pygame_events` 放行 `DROPFILE` → 设置界面里那个透明 displayable 的 `event()` 收到事件 |
| 换字体立即生效 | 重建替换表 → 清字体缓存（`renpy.free_memory`）→ 清文本排版缓存 → 重启交互 |
| 快捷键 | screen 的 `key` 语句（keysym 由引擎的 `compile_event()` 编译）；改键的捕获层用 `renpy.IgnoreEvent` 吃掉按键（`event()` 返回任何值都会被当成"本次交互结束"，say 会就此结束、剧情前进一句）；按住 Ctrl 触发的那次快进会被立刻停掉（`config.skipping` 未文档化，封在引擎适配层）—— 快进的判断跑在渲染树之前，捕获层拦不住它开始 |

表里带引擎内部结构的那几项（默认语言节点、`generation` / `scanstrings`、
渲染树、`Text.text_parameter`）都封在 `livetl/livetl_engine.rpy` 这一个文件里：
其它文件只调用它的 `livetl_engine_*` 函数，引擎换版本时改动面只有那一处。
每次启动写进 `game/livetl.log` 开头的 `engine:` / `engine seam:` 几行，就是
当前引擎上这些接口的可用性自检结果。

对话的 tl 条目里，**没翻过的一律是空字符串**——"空 = 没翻、有内容 = 翻了"。
字符串条目的 tl 模板保留原文（空串会让菜单项变成不可点的空按钮），
所以插件的判断是"译文和原文一样 = 还没翻"，界面上会标成「未翻」。

## 兼容性

- 在 Ren'Py **8.1.1** 与 **8.5.3** 上完整流程实测通过：
  主界面设置 → 生成模板 → 游戏内显示原文 → 中文输入 → 提交写回 → 热重载后立即生效
- 菜单列表、拾取模式、字符串写回与查重体检同样在两版上验证过
  （8.1 的自动化测试框架不支持 `advance` 等语句，8.1 侧用沙盒自检脚本覆盖）
- 依赖游戏的 `game/tl/` 目录可写（脚本目录形式的游戏）

## 已知限制

- 拾取到对话文本时会切到对话面板里翻译；菜单还开着时点【回菜单】回到列表
- 输入框、图标按钮、动态拼接出来的文本拾取不到（拾取时顶部提示条会说明原因），
  这类文本要直接翻 tl 里的模板条目，例如 `_("Page {}")`
- 不做 `{#tag}` 上下文区分：同一原文沿用同一译文，界面上会提示"（重复）"
- 一条译文对应一句，暂不支持跨句合并或拆分
- 译文里如果带图片、表情文字这类"不是字的元素"，鼠标定位会退让：点击只挡住、不移动
  光标（`livetl.log` 里会有 `input_map=no` 或 `input/marks` 的记录），键盘操作不受影响

  `config.font_replacement_map` 批量映射字体，并在此基础上做了自动化
  （自动扫描游戏字体、自动执行）。
  许可证副本见 `licenses/Renpy_fonts_replacement-LICENSE.txt`。
- 翻译文件的生成、写回与重载均基于 **Ren'Py** 官方接口
  （`renpy.translation.generation`、`renpy.reload_script()`、
  `renpy.get_translation_identifier()` 等）。
